How to use your planner

  1. Monthly budget — pick a month, set planned amounts for every income and expense, then type actuals as you spend.
  2. Savings goals & debt — set targets and update them whenever you save or pay down.
  3. Bills — add each bill and tick it off per month, so nothing sneaks up on you.
  4. Print / PDF — any page can be printed or saved as PDF. Everything saves automatically on this device.
